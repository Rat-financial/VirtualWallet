# 💰 數位錢包系統 (Virtual Wallet System)

一個基於 Flask 開發的全功能數位錢包管理系統，支援用戶註冊、KYC 認證、儲值、轉帳等功能。

## 📋 功能特色

### 用戶功能
- **帳號管理**
  - 註冊新帳號
  - 安全登入/登出
  - 查看個人資訊與錢包餘額

- **KYC 實名認證**
  - 提交身分證明文件
  - 追蹤審核狀態
  - 通過認證後才能進行轉帳

- **儲值功能**
  - 申請儲值請求
  - 等待管理員審核批准

- **轉帳功能**
  - 轉帳給其他用戶（需通過 KYC）
  - 即時更新餘額
  - 完整交易記錄

- **交易紀錄**
  - 查看所有收入與支出
  - 包含時間、對象、金額等詳細資訊

- **系統公告**
  - 查看最新系統公告與通知

### 管理員功能
- **用戶管理**
  - 查看所有用戶資訊
  - 重設用戶密碼
  - 監控用戶餘額

- **KYC 審核**
  - 審核用戶 KYC 申請
  - 批准或駁回認證請求

- **儲值審核**
  - 審核儲值申請
  - 批准後自動更新用戶餘額

- **公告管理**
  - 發布系統公告
  - 刪除舊公告

## 🚀 快速開始

### 環境需求
- Python 3.7+
- pip

### 安裝步驟

1. **克隆專案**
   ```bash
   git clone <repository-url>
   cd VirtualWallet
   ```

2. **建立虛擬環境**（建議）
   
   **macOS / Linux:**
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
   
   **Windows:**
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

3. **安裝依賴**
   ```bash
   pip install -r requirements.txt
   ```

4. **啟動應用程式**
   ```bash
   python app.py
   ```

5. **訪問系統**
   - 在瀏覽器中開啟: `http://127.0.0.1:5000`

6. **停用虛擬環境**（使用完畢後）
   ```bash
   deactivate
   ```

## 💾 資料儲存

系統使用 JSON 檔案 (`wallet_data.json`) 作為資料庫，包含：
- 用戶資料（帳號、密碼、餘額、KYC 狀態等）
- 交易記錄
- 待審核的儲值申請
- 系統公告

## 🔧 技術架構

### 後端
- **Flask**: Web 框架
- **Python**: 主要開發語言
- **JSON**: 資料存儲格式

### 前端
- **Bootstrap 5**: UI 框架
- **Jinja2**: 模板引擎

### 架構模式
- **資料存取層 (Data Access Layer)**: 負責資料的讀取與寫入
- **業務邏輯層 (Business Logic Layer)**: 封裝於 `DigitalWalletSystem` 類別
- **展示層 (Presentation Layer)**: Flask 路由與 HTML 模板

## 📖 使用說明

### 一般用戶流程

1. **註冊帳號**
   - 在首頁填寫帳號、密碼、姓名進行註冊

2. **登入系統**
   - 使用註冊的帳號密碼登入

3. **完成 KYC 認證**（如需轉帳）
   - 在個人儀表板提交身分證字號
   - 等待管理員審核

4. **申請儲值**
   - 輸入儲值金額
   - 等待管理員批准

5. **進行轉帳**
   - 輸入接收者帳號與金額
   - 確認轉帳（需已通過 KYC）

6. **查看交易記錄**
   - 在儀表板檢視所有交易明細

### 管理員流程

1. **登入管理後台**
   - 使用管理員帳號登入

2. **審核 KYC**
   - 檢視待審核的 KYC 申請
   - 批准或駁回

3. **審核儲值**
   - 檢視待審核的儲值申請
   - 點擊批准後自動入帳

4. **管理用戶**
   - 查看所有用戶資訊
   - 必要時重設用戶密碼

5. **發布公告**
   - 發送系統公告給所有用戶
   - 管理和刪除公告

## 🔐 安全注意事項

⚠️ **此專案僅供學習與展示用途，不建議直接用於生產環境！**

在生產環境部署前，請務必：

1. **密碼安全**
   - 使用加密方式儲存密碼（如 bcrypt）
   - 目前密碼以明文儲存，有安全風險

2. **Session 金鑰**
   - 修改 `app.secret_key` 為強隨機字串
   - 不要在程式碼中寫死

3. **資料庫**
   - 改用真實資料庫（如 PostgreSQL、MySQL）
   - JSON 檔案不適合多用戶並發環境

4. **輸入驗證**
   - 加強所有用戶輸入的驗證與過濾
   - 防止 SQL 注入、XSS 等攻擊

5. **HTTPS**
   - 在正式環境使用 HTTPS
   - 保護傳輸中的敏感資料

6. **日誌與監控**
   - 加入完整的日誌系統
   - 監控異常交易行為

## 🛠️ 自訂與擴展

### 修改預設管理員帳號
編輯 `app.py` 中的 `load_data()` 函數：

```python
"admin": {
    "password": "your_new_password",
    "name": "您的名稱",
    # ...
}
```

### 更改端口
修改 `app.py` 最後一行：

```python
app.run(debug=False, port=你的端口)
```
